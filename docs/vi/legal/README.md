# Tài Liệu Pháp Lý (VI)

Thư mục này chứa các tài liệu diễn giải pháp lý cho bản phát hành v1.0.

Hiện tại:
- `licensing.md`: giải thích mô hình license tổng thể của OCP-OCL.
- `commercial.md`: giải thích khi nào cần đi theo nhánh thương mại và giới hạn của commercial path.
- `governance.md`: giải thích ai có quyền chốt release/policy và official build nên được hiểu thế nào.
- `trademark.md`: giải thích ranh giới giữa official build và fork/community build.

Trạng thái hiện tại:
- nhánh `docs/vi/legal/*` đã có đủ các file public-facing trọng yếu;
- phần còn lại của Gate `1.0-F/1.0-G` là các file legal ở root repo và bộ test/legal contract tương ứng.
