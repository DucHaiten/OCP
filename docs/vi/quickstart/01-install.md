# Quickstart 01 - Cài đặt

## Windows
- Cài bằng installer `ocp-v1.0.0-setup-win-x64.exe` hoặc bản portable zip.
- Installer này có icon OCP, cho phép chọn thư mục cài đặt, và hỏi rõ bạn có muốn thêm `ocp` vào system `PATH` hay không.
- Installer này cài `ocp.exe`, `ocp-lsp.exe`, `ocp-dap.exe`, và bundle kèm `ocp-vscode-v1.0.0.vsix`.
- Nếu máy có VSCode ở vị trí chuẩn hoặc có `code` CLI, installer sẽ tự cài VSCode extension.
- Nếu auto-install không chạy, dùng file VSIX được cài kèm để cài thủ công.

## Linux/macOS
- Dùng tarball phù hợp nền tảng và thêm `ocp` vào `PATH`.

## Verify trước khi chạy
- Đọc `docs/vi/security/verify-download.md`.
