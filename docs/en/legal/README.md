# Legal Docs (EN)

This folder contains the public-facing legal interpretation docs for the OCP v1.0 release.

This tree is written for readers who need to answer practical questions quickly:
- what the OSS license is;
- when the commercial path is relevant;
- how governance should be understood;
- how official branding and trademark rules work.

Files in this folder do not replace the root legal/governance source files such as:
- `LICENSE`
- `GOVERNANCE.md`
- `TRADEMARK.md`
- `CODEOWNERS`

Current files:
- `licensing.md`
- `commercial.md`
- `governance.md`
- `trademark.md`
