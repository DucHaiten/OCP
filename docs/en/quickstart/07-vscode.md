# Quickstart 07 - VSCode

- If the Windows installer already auto-installed the extension, just restart VSCode.
- Otherwise install `ocp-vscode-v1.0.0.vsix`.
- Open `.ocp` files for syntax highlighting and snippets; in trusted workspaces the extension starts bundled LSP/DAP runtimes.
- In trusted workspaces, use the extension command bridge to run `fmt`, `check`, `doctor`, `fix --plan`, open artifact traces, and use hover/completion/rename/semantic tokens/debug adapter features.
